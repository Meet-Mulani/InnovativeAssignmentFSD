# PawsOut — Pet Sitter & Care Platform
A MERN platform featuring coordinate-based radius sitter discovery, accredited credential verification, structured medical/diet cards with PDF export, and a real-time daily routine tracker.


## Tech Stack
-  Frontend: React.js, Tailwind CSS, Lucide Icons, Vite
-  Backend:  Node.js, Express.js, Socket.io
-  Database:  MongoDB (2dsphere geospatial indexing, Mongoose ODM)
-  Media Storage:  Cloudinary / AWS S3 (Certificates & Care photos)

## Core Features
1. Coordinate-Based Geospatial Sitter Discovery
2. Multi-Body Certification Management (CPPS, IPPC, First Aid, etc.)
3. Structured Medical & Diet Cards + Single-Page PDF Dossier Export
4. Real-time Daily Care Tracker (Food, Medicine, Walk, Sleep)
5. Sitter Availability
6. Two-Way Review System
7. Verified Sitter Badge
8. Multi-Attribute Filter Bar (Radius, Verification, Ratings, Dates)
